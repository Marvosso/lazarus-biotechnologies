# Commit Convention

Lightweight prefixes for Lazarus Biotechnologies so `git log --oneline` tells the story of the lab.

Do not obsess over perfect Conventional Commits syntax.

## Prefixes

- `docs:`
- `feat:`
- `fix:`
- `refactor:`
- `test:`
- `chore:`
- `security:`

## Examples

```text
docs: establish information classification standard
feat: add employee activity simulator
feat: onboard Windows endpoint telemetry
fix: correct Wazuh agent connectivity
security: restrict ORION data access
test: validate authentication event collection
docs: document first access review
```
